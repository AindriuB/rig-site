The narrow push

rig push takes a task id or a branch name and nothing else. It cannot push the default branch, a tag, a refspec or a force push, so it is safe to allow without a prompt.

✓ Accepted

  • rig push <task id>
  • rig push task/<name>
  • rig push record/<name>

A branch by task id or name that exists locally and is not the default branch. It goes to the branch of the same name on origin.

✕ Refused

  • Refused: the default branch
  • Refused: a tag
  • Refused: a refspec
  • Refused: a force push

There is no option for another remote, a force push or tags.
